# MASTER_PLAN.md — مدرستي: التصور النهائي وخطة التنفيذ الكاملة

> المرجع الدائم للتنفيذ. أي ميزة جديدة يجب أن تطابق هذا الملف و `docs/PROJECT_DNA.md`.
> يُحدَّث عمود الحالة بعد إنهاء كل موديول. المصدر الأصلي للمتطلبات: ملفات المواصفات الثلاثة في جذر المشروع.

## طريقة العمل (متفق عليها مع صاحب المشروع)

- التنفيذ موديول وراء موديول **بدون انتظار موافقة** بين الموديولات، بالترتيب المكتوب هنا.
- كل موديول يمر بنفس المراحل: **DB → Services → UI → Checks → QA (متصفح + API + DB) → commit محلي**.
- **لا رفع على GitHub** إلا عند انتهاء النظام كله، أو إذا طلب صاحب المشروع ذلك صراحة (ثم نكمل العمل).
- حسابات الاختبار في بيئة التطوير كلمة مرورها `12345678a` (مسجلة في `apps/web/.env.test.local`).
- الردود لصاحب المشروع بالعربية المصرية البسيطة.

## 2. نموذج البيانات المستهدف (الجداول الجديدة)

> كل جدول: `school_id` + FKs مركّبة `(x_id, school_id)` + RLS + فهارس + DEFERRABLE FKs لحماية الحذف.

| المرحلة | الجداول | ملاحظات |
|---|---|---|
| P1 | (موجودة) `staff_roles`, `staff_role_permissions`, `profile_staff_roles`, `profile_permissions` | + دالة `private.has_feature(key)` لفرض الباقات على مستوى DB |
| P2 | `periods` (رقم الحصة، البداية، النهاية) · `timetable_entries` (class_subject_id, weekday, period_id) | قيد: لا تعارض للفصل ولا للمعلم في نفس الحصة |
| P3 | `attendance_records` (student_id, class_id, date, status: present/absent/late/excused, note, recorded_by) | unique(student_id, date) · Trigger إشعار لولي الأمر عند الغياب |
| P4 | `homework` (class_subject_id, title, body, due_at, attachments) · `homework_submissions` (homework_id, student_id, body, attachments, submitted_at, score, feedback, graded_by) | Bucket خاص `homework` |
| P5 | `exams` (class_subject_id, kind: monthly/midterm/final/quiz, mode: paper/online, starts_at, duration, max_score, status: draft/pending/approved/published) · `question_bank` · `exam_questions` · `exam_attempts` (answers jsonb, submitted once) · `exam_results` (score) | RPC `start_exam` / `submit_exam` — جلب الورقة مرة واحدة وتسليم دفعة واحدة |
| P6 | `monthly_reports` (student_id, month, academic_note, behavior_note, ratings jsonb, status: draft/sent) | إشعار لولي الأمر عند الإرسال |
| P7 | `notifications` (recipient_id, kind, data jsonb, read_at) — **أُنشئ في P3** مع إشعار الغياب | تكتبها Triggers فقط · قراءة صاحبها فقط · P7 يضيف الواجهة وبقية الأنواع |
| P9 | `fee_items`, `fee_payments` (مدرسة) · `plans`, `school_subscriptions`, `platform_transactions` (منصة) | finance.* · المالك العام فقط للمنصة |
